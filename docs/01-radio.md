# 第1堂｜2.4GHz 與單向通訊

2026/12/03｜19:10-21:20｜130分鐘


## 學習目標與講授重點

能說明發送端、接收端、頻道、位址與封包的關係；能辨認 SPI 的 MOSI/MISO/SCK，知道 nRF 裸模組供電為 3.3V。2.4GHz 是頻段，nRF24L01+ 並不是 Wi-Fi 或藍牙；不同裝置可能互相干擾。

以「教室＝頻道、收件地址＝pipe address、信件＝payload」類比；CRC 檢查傳輸錯誤，硬體 ACK 表示無線端收到資料，不保證應用程式已完成動作。此堂的應用資料只有發送端→接收端，仍使用反向硬體 ACK。

## 實作步驟

1. 先把馬達電池盒開關關閉且不接 VM；兩端只接 RF 與 USB。依模組絲印查腳位，不以天線朝向猜測。

2. 設定個人車輛兩端 VEHICLE_ID 相同，每人用 1-10 的不同車號。程式自動設定頻道 25、30…70，位址也含車號；資料速率為 250kbps、低發射功率。

3. 在約1公尺、天線無金屬遮擋的桌面測試。正常時發送端 ACK=1，接收端序號每200ms更新一次。

4. 記錄100筆傳送中的 ACK 成功次數；暫以至少95筆為課堂檢核目標，未達標先修供電與接線，不直接提高功率。

提問：收到序號缺號可能代表什麼？如果 ACK=1，能否推論馬達已經轉動？答案：不能，還要應用回報或實際感測。
