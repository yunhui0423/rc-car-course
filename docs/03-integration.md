# 第3堂｜整車與雙向回傳

2026/12/17｜19:10-21:20｜130分鐘


## 學習目標與講授重點

把搖桿命令封裝成資料，送往車端；車端將「已處理序號、左右PWM、停止狀態」放入下一次 ACK payload 回傳。兩端交替收發，屬半雙工應用；並非同一瞬間雙向傳輸。

ACK payload 須預先放入 RF 晶片，收到當次封包時硬體已立刻送 ACK，因此回報通常是前一次命令的處理結果。以回報序號對照，不以這份回報冒充即時車速或電量。

|---|---|---|
| 19:10-19:25 / 15分 | 封包與半雙工／ACK payload | 比對Command與Status欄位 |
| 19:25-19:50 / 25分 | 整合程式與重新接線 | 搖桿移回Nano A0/A1/D2；上傳Remote與Car |
| 19:50-20:10 / 20分 | 架空整車驗證 | Car先維持MOTOR_ENABLED=false，確認回傳 |

| 21:00-21:20 / 20分 | 成果驗收與回饋 | 示範失聯停止、恢復置中；提交驗收單 |


## 行駛邏輯與失效處理

1. 車端預設 MOTOR_ENABLED=false。確認接線與架空測試通過後，教師才協助改 true 並重新上傳。

2. 上電或失聯後先收到「搖桿置中且按鍵放開」才解除鎖定；之後按住按鍵並移動搖桿行駛。命令每50ms送一次，PWM上限120/255。

3. 鬆開按鍵、搖桿回中或500ms沒有有效命令時，PWM歸零且STBY拉低。車輪會滑行，停車距離必須實測；這不是機械急煞。

4. 任一輪被要求由正轉直接切反轉會鎖定停止。需先回中、放開按鍵，再按住執行新方向；原地旋轉前也先停止。

5. 失聯復原後仍按住推桿，車子必須維持停止。先回中放開才能再啟動。示範時用關閉遙控器，勿短接供電製造斷訊。

任務：低速前進1公尺→停止→轉向→到站；再於架空狀態示範斷訊與重新啟用。場邊安排一位助教可直接關閉車上 VM 開關。
