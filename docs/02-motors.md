# 第2堂｜搖桿、PWM 與馬達

2026/12/10｜19:10-21:20｜130分鐘


## 學習目標與講授重點

雙軸搖桿是兩個可變電阻加按鈕。ATmega328P 類比讀值為 0-1023；analogWrite 的控制值為 0-255，代表 PWM 占空比，不是直接輸出可調直流電壓。馬達由驅動板供應電流，Arduino 腳位只給邏輯訊號。

H橋切換電流方向以控制正反轉。兩輪差速用 L = 油門 + 轉向、R = 油門 - 轉向，再限制到允許範圍。左右輪實際轉向還受安裝方向影響，需逐輪確認。

## Bench 暫接步驟

1. 此堂將搖桿暫接 Uno：VRx→A0、VRy→A1、SW→D12，VCC→5V、GND→GND。D2 已供馬達使用，不可把 SW 接 D2。RF 可先拔除，重新接線前斷電。

2. 上傳 Bench；開機保持搖桿置中約0.5秒以平均100次讀值。若中心不在300-720內，程式不啟動，檢查接線後重啟。中心附近±60設死區。

3. 車輪確實架空後接 VM。按住搖桿按鍵才允許馬達動作，鬆開或置中即停止命令。Bench 最大PWM100，初次測試可先改成60。

4. 前推若兩輪反向，調整軸向；單輪反向則斷電後交換該輪馬達兩線，或改 LEFT_SIGN/RIGHT_SIGN。不要帶電換線，也不要直接由前進切後退。

課堂檢核：PWM為0不動、低PWM可能不足以起轉、PWM提高通常更快但不等於固定速度。沒有編碼器，不能宣稱完成轉速閉迴路控制。
