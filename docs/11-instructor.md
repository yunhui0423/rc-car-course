# 助教備課與除錯

全班10人獨立製作。建議一位主講、至少兩位助教逐人檢查接線；這是人力建議，並非原案已確認配置。課前完成底盤、馬達焊線、去耦與排針，課內集中在程式和除錯。

| 期限 | 完成項目 |
|---|---|
| 11/12前 | 確認人數、盤點現有器材、首件詢價 |
| 11/19前 | 首件編譯、燒錄、供電及電流驗證 |
| 11/26前 | 批量收件、逐套標車號、兩片RF配對 |
| 12/02前 | 每人電腦與USB檢查、試教、AA充電 |

未通過首件電流、供電與停止測試，不讓學生做落地行駛。路線任務每次一人進場，其餘車VM關閉。

| 現象 | 排查順序 |
|---|---|
| 沒有序列埠 | USB資料線、插孔、CH340驅動、板卡 |
| radio.begin失敗 | RF供電、模組插向、CE/CSN、固定SPI腳、焊點 |
| ACK一直0 | VEHICLE_ID、頻道、速率、兩端程式是否同階段 |
| 馬達動就重啟 | VM電池與線徑、共地、去耦、RF遠離馬達線 |
| 有回報但不動 | MOTOR_ENABLED、置中放開解鎖、按住SW、STBY、VM |
| 回中仍轉 | ADC接線、中心校正、死區、SW腳位 |
| 突然反向後不動 | 換向鎖定；回中放開，再按住 |
| 經一段時間關機 | 行動電源低負載及低電流模式退出規則 |

每次只改一個條件；先斷VM處理，再用已知正常的RF模組／線材交叉測試。不要直接提升發射功率掩蓋供電問題。禁止學生長時間堵住轉軸驗證堵轉電流。

課後逐人保存進度與故障紀錄；電池成套標記，同一盒不混電量。每次課後VM關閉、USB拔除，充電另安排。
