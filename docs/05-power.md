# 供電設計與首件驗證

先確認供電，再確認程式；所有換線均先斷電


## 三條電源路徑

| 路徑 | 接法 | 不可省略的檢查 |
|---|---|---|
| 遙控端邏輯 | 5V行動電源→Nano USB→搖桿／RF用3.3V穩壓模組 | 低負載時不可自動關機；裸RF端量到約3.3V |
| 車端邏輯 | 另一個5V行動電源→Uno USB→驅動VCC／RF用3.3V穩壓模組 | 電腦上傳時先拔行動電源USB，再換電腦USB |
| 車端馬達 | 4顆AA鎳氫→電池盒開關→TB6612 VM | AA負極、驅動GND、Uno GND接共地；正極不互接 |

馬達供電不接 Arduino VIN、5V 或 USB，電池組正極也不接 RF。遙控器與車體之間不用接任何線。標稱4.8V不代表滿電固定4.8V；量測實際電壓並確認馬達、驅動板允許。


## 電流與去耦

選擇3-6V TT馬達，取得額定與堵轉電流資料。TB6612FNG 每路額定平均輸出常列1.2A，3.2A是有時間條件的峰值，不可當連續負載。模組散熱、銅箔與端子可能更限制電流，須依實際模組規格降額。不能僅憑「TT」名稱決定可用。

每片 RF 旁放100uF電解與0.1uF陶瓷電容；每顆馬達兩端焊0.1uF；驅動VM/GND旁放470uF。選含原廠建議VCC／VM旁路電容的模組，額外大電容不能替代板上必需去耦。電解負腳接GND。


## 教師首件測試清單

1. 無電時量導通、確認無5V/GND短路；確認馬達與邏輯正極分開。先上USB量RF供電，馬達電池仍不接。

2. 用可限流電源與供應商資料驗證單顆馬達的空載、啟動與短暫負載電流；禁止學生用手長時間堵住轉軸。若電流不符合驅動板限制，換低電流馬達或較高容量驅動器後重新設計。

3. 測試單輪正反向、雙輪同時啟動、轉彎負載，檢查驅動板與接頭溫升及RF是否重啟；首件未過不批量採購。

4. 驗證放手、回中、關遙控、重啟車端、恢復訊號不自動行駛。量測停止延遲與滑行距離；500ms為軟體門檻，實際端到端延遲需記錄。

5. 行動電源至少做30分鐘低負載與馬達啟停測試；充滿AA後進行一次完整130分鐘課程模擬，不預先保證續航。

充電只用相容AA鎳氫充電器；同一電池盒內的電池須同型號同電量。電池異常發熱或破損即停用。此版不使用方形9V電池、裸18650或2串鋰電池組。
