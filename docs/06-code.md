# 程式使用與授課引導

範例程式獨立放在`sketches/` 資料夾

| 課次 | 檔案／上傳目標 | 學生應修改／觀察 |
|---|---|---|
| 第1堂 | PingTx→Nano / PingRx→Uno | 個人兩端VEHICLE_ID一致；改錯頻道／位址後復原 |
| 第2堂 | Bench→Uno | 死區±60、PWM上限100、左右輪方向；SW接D12 |

## 準備與上傳

1. Arduino IDE 安裝 Arduino AVR Boards；程式庫管理員安裝 RF24（TMRh20）。本包依RF24的ACK payload用法撰寫；每端使用相同版本，建議先以1.6.1做實機驗證。

2. Nano 選 ATmega328P；若相容板上傳不同步，查供應商說明，可能需 Old Bootloader；Uno 選 Uno。確認USB資料線、序列埠與驅動程式。

3. 上傳時關閉序列監控；完成後以115200開啟。每人用一台電腦連接兩塊板卡，選對各自序列埠並輪流查看監控；若需同時查看，使用可分別指定序列埠的兩個監控視窗；馬達測試時車輪架空，避免USB線拉扯。

4. 每次修改先寫「預測結果」，只改一個變數再上傳。保存個人車號、版本、校正方向與測試日期。


## 用這些例子解釋資料處理

Command：seq是命令序號，throttle是前後油門，turn是左右轉向，enable是按鍵狀態。Status：seq是已處理序號，left/right是輸出的有號PWM，stopped是是否下達停車。兩個封包各7 bytes，遠低於nRF單包32 bytes限制。

搖桿中心以100次讀值平均；死區內輸出0，死區外縮放到最大值。例：油門80、轉向20 → 左100、右60。油門0、轉向80 → 左80、右-80，須在停止後開始，避免直接反轉。PWM是命令，不能直接換算公尺／秒。


## 編譯與硬體驗證狀態

已使用 Arduino AVR Boards 1.8.6 與RF24 1.6.1完成5份範例編譯，另確認Car馬達啟用版本可編譯。Nano目標為ATmega328P、Uno為Uno R3；程式與RAM用量均未超限。尚未燒錄，也沒有電流、通訊距離或實車驗證。助教須依實際板卡上傳，再執行供電與驗收文件測試。

若要保留原四輪：不能直接把兩顆TT並到每個通道便宣稱完成。須按每側兩馬達的啟動與負載電流合計重選驅動器、電池、線材；L298N接線與本程式不同，另需調整腳位與供電，這份程式不可直接套用。
